# Neon Console Audio Player

Навчальний аудіоплеєр на WPF із нестандартним безрамковим вікном, насиченим неоновим оформленням і трьома змінними скінами.

## Можливості

- вибір локальних файлів `MP3`, `WAV`, `WMA` і `M4A`;
- запуск, пауза/продовження та повна зупинка відтворення;
- часова шкала з поточним часом, тривалістю і перемотуванням;
- регулятор гучності;
- скіни **Cyan Circuit**, **Magenta Pulse** та **Ultraviolet Grid** без переривання поточного треку;
- нестандартна форма вікна зі зрізаними кутами, власними кнопками згортання/закриття та перетягуванням;
- анімовані сканувальні лінії, індикатори, світіння, технічна сітка й векторний шар друкованої плати;
- клавіатурні скорочення: `Ctrl+O` — відкрити файл, `Space` — пауза/продовження, `Esc` — зупинка.

## Запуск у Visual Studio

1. Відкрийте [NeonAudioPlayer.sln](NeonAudioPlayer.sln) у Visual Studio 2022.
2. Дочекайтеся завантаження проєкту `NeonAudioPlayer`.
3. Оберіть конфігурацію `Debug | Any CPU`.
4. Натисніть `F5` або кнопку **Start**.
5. У програмі натисніть **OPEN SOURCE**, оберіть аудіофайл і натисніть **PLAY**.

Потрібні Windows 10/11, Visual Studio 2022 з workload **.NET desktop development** та .NET 8 SDK. Сторонні NuGet-пакети не використовуються.

## Структура

- `NeonAudioPlayer/App.xaml` — глобальна палітра, градієнти, стилі, шаблони кнопок і повзунків.
- `NeonAudioPlayer/MainWindow.xaml` — форма вікна, повний UI, декоративні шари й анімації.
- `NeonAudioPlayer/Themes/CircuitDecorations.xaml` — векторний повторюваний фон друкованої плати.
- `NeonAudioPlayer/MainWindow.xaml.cs` — мінімальна імперативна логіка відтворення, діалогу файлів, часу та скінів.
- `NeonAudioPlayer/PlayerLogic.cs` — тестована логіка форматування часу й доступності перемотування.
- `tests/*.ps1` — поведінкові й структурні перевірки без зовнішнього тестового фреймворку.
- `scripts/verify-xaml-ratio.ps1` — контроль вимоги про щонайменше 90% XAML.

## Перевірка

У PowerShell із кореня проєкту:

```powershell
powershell -ExecutionPolicy Bypass -File tests/PlayerLogic.Tests.ps1
powershell -ExecutionPolicy Bypass -File tests/ProjectContract.Tests.ps1
powershell -ExecutionPolicy Bypass -File scripts/verify-xaml-ratio.ps1
```

Остання команда рахує непорожні рядки лише в рукописних `.xaml` і `.cs` файлах, ігноруючи `bin` та `obj`. Перевірка завершується помилкою, якщо частка XAML менша за 90%.

## Архітектурне рішення

Проєкт свідомо побудований у стилі **XAML-first**. Розмітка містить ресурси, геометрію, шаблони контролів, візуальні стани, палітри й анімації; C# залишено тільки для дій, які потребують API операційної системи або керування `MediaElement`. Це робить проєкт зручним для демонстрації можливостей WPF і виконує вимогу лабораторної роботи щодо домінування XAML.
